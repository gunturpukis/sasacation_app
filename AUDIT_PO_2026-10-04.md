## 1. Ringkasan satu paragraf

Aplikasi Flutter Sasacation diaudit terhadap desain Figma (12 frame, via
Figma API), diperbaiki dari sisi navigasi, guest mode, parity fitur
(F1–F16 backend), dan Sprint 1 domestik (Rp, Bahasa Indonesia, countdown
pending). Fondasi visual 100% setia pada Figma; funnel OTA inti utuh dan
jujur (no-fake-data). **Penilaian PO: 80% siap demo investor, 50% siap
publik** — selisihnya ada pada 4 item P0 (§6).

## 2. Kesesuaian desain vs Figma

| Area | Status |
|---|---|
| Design token (warna, Plus Jakarta Sans, radius, shadow, spacing) | ✅ 100% match (terverifikasi dari node tree API Figma) |
| Home, Search, Detail, Saved, AI Chat, Checkout, Profil, Settings inti, Notifikasi | ✅ 85–95% (gap kecil terdokumentasi) |
| Trip Planner, Wallet, Impact Score | ❌ disengaja — butuh backend/keputusan (tidak dikarang) |
| Bottom-nav IA | ⚠️ divergen dari Figma — butuh keputusan desain (Discover/Trips/Sasa AI vs Home/Explore/Bookings/Profile) |

## 3. Yang sudah dikerjakan (kronologis)

1. **Audit UI + bug kritis:** duplikat route AI, path 404 trip/kategori,
   unifikasi `Navigator.push` → `context.push`, `guestAccessible`,
   typo route, anti-crash `extra`, CTA mati, peta → Google Maps.
2. **Guest mode end-to-end:** splash/onboarding → `/home` tanpa login;
   tombol tamu di login; gate tab Bookings/Profile; wishlist guest
   (state lokal).
3. **P2 (UI murni):** Recent Searches + AI Pick, filter + grouping
   notifikasi, preview Upcoming Trips, badge wishlist heuristik,
   taksonomi kategori (7 item).
4. **P3 (butuh backend, sisi Flutter):** model + section Guest Reviews,
   Personal Info (`PUT /auth/profile`), Security (password via backend,
   reset via Firebase), Lupa Password real, kontrak Wallet/Impact/
   saved-methods (tanpa UI palsu).
5. **Handoff backend F1–F11** (tiap item diverifikasi curl): pending +
   resume, discovery shuffle, amenities + sort server-side, PayPal +
   cleaning fee + kartu tersimpan + toggle save, settings server,
   itinerary pindah ke backend (+ overlay lokal), polls + vote +
   notifikasi action generik 9 rute, groups + gap banner, loyalty pass +
   transfer, tasks, reschedule + selisih harga.
6. **Handoff F12–F16:** tombol Unduh Invoice (PDF), kartu Destination
   Alert (detail hotel + tab Explore berbasis GPS), kurs dari kontrak
   F14 (`settings` + `pricing.fx`), status refunded, chip kategori
   `available:true` (+Destinations terverifikasi).
7. **Sprint 1 domestik:** `ForexService` + `MoneyText` di ±30 titik harga
   (USD sampai rate live, lalu Rp + label estimasi); l10n penuh
   (489→505 key ID/EN parity, selector bahasa tersimpan server);
   countdown pending `HH:MM:SS` dari `expiresAt` resume.
8. **Sprint 2 (selesai):** urutan bayar per-locale (ID: QRIS → e-wallet →
   transfer → kartu → PayPal), kotak kebijakan reschedule/refund sebelum
   bayar, `LOYALTY_DEFINITION.md`, AI planner **real** (mock ±300 baris
   dihapus; parameter terstruktur → `POST /ai/trip-plan`).

## 5. Keputusan produk yang dikunci

1. User utama = **turis domestik**; Bahasa Indonesia primer.
2. Wallet = **loyalty points saja** (hindari izin e-money BI);
   transfer dibatasi ke poin.
3. Prinsip **no-fake-data**: section disembunyikan bila API kosong/404.
4. Kurs hanya dari kontrak F14 (tidak ada hardcode di client).
5. Kategori hanya yang `available: true` (+Destinations terverifikasi).

## 6. UTANG TERBUKA — P0 sebelum rilis publik ⚠️

1. **Transfer rupiah masih hidup di UI** (`Payment History` → dialog
   `POST /wallet/transfer` USD) — melanggar keputusan #2 dan mati fungsi
   (saldo selalu 0). Tindakan: sembunyikan sampai endpoint
   `POST /loyalty/transfer` (poin) ada.
2. **Tamu masih lihat USD** (`GET /settings` butuh auth). Tindakan BE:
   endpoint kurs publik atau selipkan rate di respons hotel.
3. **Kualitas AI planner belum diuji 10 query** (sampel terpantau:
   tanggal 2023, tema meleset). Tindakan BE: tanggal relatif + uji mutu.
4. **Nol analytics + crash reporting** — semua optimasi buta tanpanya.

pending; Help Center ID; kebijakan pembatalan per-properti.
